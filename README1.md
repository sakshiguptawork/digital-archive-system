# Cloud-Based Digital Archive System

A secure and efficient platform for storing, managing, and accessing historical documents and records. This system ensures document preservation, improves accessibility, and streamlines retrieval processes for archivists, researchers, and public users.

---

## 👥 User Roles & Features

### 1. Archivist
* **Archive Management:** Upload documents, input metadata, and manage digital preservation.
* **User Access Management:** Review and approve/reject user access requests.
* **Document Preservation:** Monitor preservation status and digital formats.

### 2. Researcher
* **Document Search:** Use advanced search tools and filters to locate records.
* **Document Access:** Request and view restricted research documents.
* **Annotation and Notes:** Add private annotations and save research notes.

### 3. Public User
* **Public Document Search:** Search through open-access historical documents.
* **Document Viewing:** Clean interface for reading public records.
* **Feedback Submission:** Submit feedback or inquiries regarding the archive.

---

## 🚀 Tech Stack
* **Frontend:** React.js / Vite
* **Backend:** Node.js, Express.js
* **Database & Storage:** MongoDB / Cloud Object Storage (e.g., AWS S3 / Firebase Storage)
